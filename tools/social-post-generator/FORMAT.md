# allmath Telegram Caption Style

Это канон выхода для генератора. Пользователь не обязан заполнять шаблон.

Цель: короткий живой комментарий к карточкам, не автоклон Школково и не
нейро-лонгрид. Референсы Школково полезны длиной и рубричностью, но плохо тем,
что повторяются почти дословно. Нам нужен тот же уровень простоты, но более
человеческий текст под конкретный материал.

## Caption

`post.caption` — готовый текст Telegram-поста перед карточками.

Норма:

- 180-650 символов;
- 2-4 коротких абзаца;
- серийный тег в начале: `#советы_олимпиадникам@allmath` или allmath-аналог;
- конкретный повод открыть карточки: тема, приём, тип задачи;
- мягкий финал: попробовать самому, поставить реакцию, написать тему или вопрос.

Не надо:

- копировать один и тот же Shkolkovo-блок каждый раз;
- ставить вместе все фразы `Продолжаем... / На что обращать внимание? / Всё как обычно)`;
- писать полное условие и решение в caption;
- добавлять продажу, курс, вебинар, YouTube, если этого нет во входном материале;
- использовать нейро-штампы: “магия”, “главный ход”, “не утонуть”, “ловушка”.

## Типовые Формы

Совет/шпаргалка:

```text
#советы_олимпиадникам@allmath

Сегодня коротко про <тему>. Это тот случай, когда полезно держать в голове не формулу, а пару признаков: по ним задача обычно быстро раскладывается.

На карточках — что заметить первым и как не перепутать ход решения.

Попробуйте применить к ближайшей задаче по теме и напишите, где хочется ещё такую шпаргалку.
```

Задачи на закрепление:

```text
#советы_олимпиадникам@allmath

В прошлый раз разобрали идею про <тему>, теперь давайте проверим её на задачах.

Не спешите открывать подсказки: сначала попробуйте поймать, какой признак срабатывает в каждой задаче.

Если где-то застрянете, пишите в комментарии — разберём.
```

Разбор:

```text
#советы_олимпиадникам@allmath

Разбираем вчерашние задачи и смотрим, где именно применялась шпаргалка.

Обратите внимание не только на ответ, а на момент, где решение становится коротким.

Ставьте реакции, если такой формат разборов оставить.
```

## Карточки

- 2-4 карточки на пост;
- одна карточка — одна мысль;
- математика, условия, подсказки и решение живут на карточках;
- для шпаргалки карточки отвечают “что заметить?” и “что делать?”;
- для задач карточки дают условия/подсказки/разбор;
- для разбора последняя карточка — `solution`;
- размер по умолчанию — вертикальный `portrait` 1080x1350, чтобы нормально читалось с телефона;
- формулы в LaTeX без `$$`;
- если решения не хватает, не выдумывать математику.

## JSON Contract

Главное поле для текста — `post.caption`. Renderer берёт его как готовый текст.

```json
{
  "slug": "safe-kebab-slug",
  "brand": {"name": "allmath", "handle": "@allmath"},
  "post": {
    "title": "служебный короткий заголовок",
    "caption": "#советы_олимпиадникам@allmath\n\nСегодня коротко про...",
    "hashtags": ["#советы_олимпиадникам@allmath"]
  },
  "cards": []
}
```
